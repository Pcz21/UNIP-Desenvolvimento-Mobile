# relatorio08-senhas

Código sem dependências de aplicação externas. Copie integralmente `lib/main.dart` para o modo Flutter do DartPad ou, com Flutter estável instalado, execute nesta pasta:

```sh
flutter pub get
flutter analyze
flutter test
flutter build web --no-web-resources-cdn
flutter run -d chrome
```

A avaliação é local e didática. Não usar credenciais reais. Testes executados, quando disponíveis, estão em `../../testes/RESULTADOS.md`; a presença de testes não significa que passaram.
